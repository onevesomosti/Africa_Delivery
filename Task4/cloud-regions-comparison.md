## Вывод

Для MVP предлагается использовать локального провайдера в Нигерии для хранения и обработки персональных данных нигерийских пользователей. Для Кении потребуется отдельный локальный контур. AWS, GCP и Azure в ЮАР рассматриваются как варианты для последующего выхода на рынок ЮАР и размещения разрешённых обезличенных данных.

Выбор обусловлен следующими требованиями:
- Локализация: до юридического заключения персональные данные остаются внутри страны субъекта.
- Стоимость: бюджет инфраструктуры ограничен $5000/мес.
- Доступность: первоначальная цель MVP — 99,9%, архитектурная цель — 99,99%. 
- Переносимость: необходимо сохранить возможность смены провайдера без изменения основной бизнес-логики. 

Для окончательного решения необходимо получить сопоставимые коммерческие предложения, измерить задержки из Лагоса, Найроби и Йоханнесбурга, проверить доступность необходимых сервисов и договорные SLA.

## Допущения
1. Локальный нигерийский провайдер сможет предоставить необходимую инфраструктуру для MVP. Возможности и стоимость пока не подтверждены.
2. Предполагается, что размещение инфраструктуры ближе к пользователям снижает сетевую задержку. Но фактические значения latency требуют измерений из целевых стран.
3. Стоимость облачных вариантов не ранжируется без одинаковой конфигурации ресурсов и расчёта TCO.
4. Региональные SLA относятся к отдельным сервисам и не гарантируют такую же доступность всей платформы.
