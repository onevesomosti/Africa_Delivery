# Data Residency Map

Дата актуализации: 14.10.2026 

Статус: Предварительное решение, ожидает юридического согласования 

Основные инфраструктурные провайдеры: локальные провайдеры Нигерии и Кении, AWS и GCP в ЮАР как рассматриваемые варианты 

Юрисдикции: Нигерия — NDPR / NDPA 2023, ЮАР — POPIA, Кения — Data Protection Act 2019 / KICA

## 1. Краткое резюме

Приложению необходимо обеспечить локальное хранение и защиту персональных данных покупателей и продавцов с учётом законодательства Нигерии, Кении и ЮАР.

До получения окончательного заключения юристов принимается консервативное решение: персональные данные хранятся и обрабатываются в стране субъекта, трансграничная передача по умолчанию запрещена.

Для MVP используются отдельные национальные контуры Нигерии и Кении. Для последующего выхода в ЮАР рассматриваются AWS и GCP.

Шифрование и маскирование применяются для защиты информации, но не считаются заменой требованиям локализации.

## 4. Региональные потоки данных и контроль локализации

### ЮАР — POPIA
- Размещение: AWS `af-south-1` или GCP `africa-south1`, окончательный выбор не сделан.
- Локализация: персональные данные временно остаются в ЮАР до подтверждения условий трансграничной передачи.
- Согласия: система фиксирует получение, изменение и отзыв согласия пользователя.
- Маркетинг: рассылка без подтверждённого согласия запрещена. Приобретённая база из 410 000 номеров не используется без юридического разрешения.
- Передача: зарубежная обработка блокируется до подтверждения правового основания.

Источник: артефакт 3, п. 2, артефакт 2.

### Кения — Data Protection Act 2019 / KICA
- Размещение: локальный провайдер в Кении.
- Локализация: персональные данные и связанные с платежами сведения хранятся в национальном контуре.
- Платежи: интеграция с лицензированным M-Pesa.
- Передача: трансграничный экспорт персональных данных запрещён до уточнения условий.
- Уведомления о нарушениях: точные сроки и обязанности требуют юридического подтверждения.

Источник: артефакт 3, п. 3–4.

### Нигерия — NDPR / NDPA 2023
- Размещение: локальный нигерийский провайдер.
- Локализация: персональные данные хранятся внутри страны.
- Платежи: используется лицензированный провайдер Flutterwave.
- Маскирование: рассматривается как допустимый механизм защиты, но его достаточность для передачи данных не подтверждена.
- Передача: экспорт персональных данных запрещён до получения юридического заключения.
- Регуляторные обязательства: регистрация в Комиссии, назначение ответственного за защиту данных и ежегодная аудиторская отчётность.

Источник: артефакт 3, п. 1, 4.

## 5. Защита данных и технические меры

| Механизм | Применение |
| --- | --- |
| Региональная изоляция | Раздельные национальные БД, запрет неразрешённой межрегиональной репликации |
| Шифрование | Защита данных при хранении и передаче |
| Управление ключами | Раздельные ключи шифрования для каждой страны |
| Маскирование | Сокрытие телефонов, адресов и других персональных сведений в логах |
| Контроль экспорта | Проверка категории данных и правового основания перед трансграничной передачей |
| Управление согласиями | Хранение истории предоставления и отзыва согласий |
| Аудит | Журналирование доступа и операций передачи без раскрытия персональных данных |
| Резервирование | Хранение резервных копий внутри национального контура |

Источники: артефакт 3, NFR-17, NFR-18, FMEA F-02.

## Допущения

1. Псевдонимизированные данные считаются персональными, пока юристы не подтвердят иное.
2. Для ЮАР рассматриваются AWS и GCP. Окончательный выбор зависит от стоимости, доступности сервисов и юридических условий.
3. Конкретные сроки хранения, удаления и архивирования персональных данных пока неизвестны. Они будут определены после заключения юристов.

## Итог
Для запуска MVP предлагаются два независимых национальных контура данных в Нигерии и Кении. Решение допускает последующее расширение в ЮАР и изменение правил трансграничной передачи после получения окончательного юридического заключения через четыре–шесть недель.
